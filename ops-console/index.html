Feature flags

Flags are evaluated on every call, so a change takes effect on the next request — no restart, no redeploy. Try turning redis-cache off and watch the log: reads stop consulting Redis and the service keeps working from Postgres.

Live log

These logs are written to carry identifiers rather than customer attributes, which is what makes a live tail viewable at all. The bracketed value is the first eight characters of the correlation id — hover for the whole of it — and the same id is on the error response a customer would quote.
